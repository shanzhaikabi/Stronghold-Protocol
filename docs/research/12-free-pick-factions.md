# 12 — 自选干员的主盟约 (PRTS factions)

`12-free-pick-factions.json` 是**自选干员 (自由位置) 主盟约**的权威表：`{ source, checkedAt, bonds: { [charId]: bondId | null } }`，
覆盖 `character_table.json` 里**全部 87 名不被本赛季棋子占用的六星干员**。`tools/build-data.mjs` 的 `freePickMainBond()`
优先读它（**包括 `null`，那表示"查过了，不属于这 8 个"**），只有表里没有的干员才回落到客户端数据的
`nationId` / `groupId` / `teamId` 提示。

## 为什么需要这张表

客户端数据只有 `nationId` / `groupId` / `teamId`（**所属势力**），而游戏判定盟约用的是**所属势力 ∪ 隐藏势力** ——
隐藏势力不在客户端数据里，且经常与所属势力冲突。用客户端提示推测只能命中 25/87，实测反例：

| 干员 | 客户端提示 | 实际盟约 |
|---|---|---|
| 能天使 | `lungmen`（龙门）| 拉特兰 |
| 水月 | `higashi`（东国）| 阿戈尔 |
| 卡涅利安 | `leithanien`（莱塔尼亚）| 萨尔贡 |
| 缄默德克萨斯 | `lungmen`（龙门）| 叙拉古 |

（这 4 名都在本赛季池里、不在本表的 87 名内，但同一套规则能复现它们，且水月 / 卡涅利安 / 缄默德克萨斯另有
游戏内盟约行佐证。）

## 判定规则

**盟约 = (所属势力 ∪ 隐藏势力) ∩ {阿戈尔, 卡西米尔, 拉特兰, 萨尔贡, 维多利亚, 谢拉格, 叙拉古, 炎}**，空集即
**协防干员** (`emptyShip`)。注意是**并集**而非"隐藏覆盖可见"：煌 的隐藏势力是 `炎;;维多利亚`，所以她同时属于两个
核心盟约。**龙门与炎国的一切子势力（龙门近卫局、李氏、岁 …）都算炎**。

本仓库 `server/match/PlayerState.js` 的 `freePickMainBond()` 与 `tools/build-data.mjs` 的 `FACTION_BOND` 用的是同一套
映射，只是没有隐藏势力可读，所以提示只作为**表外的兜底**。

## 数据来源与方法

PRTS (`prts.wiki`) 是 MediaWiki。`curl` / `Invoke-WebRequest` 直接请求 API 会 **403**，用 Node 的 `fetch` 可以。
关键点：

- **`Category:属于X的干员` 不是权威** —— 它只编码**可见的**所属势力（能天使在"属于炎-龙门的干员"里，不在
  "属于拉特兰的干员"里）。权威数据是 `{{属性}}` infobox 的 **所属势力** 与 **隐藏势力**（PRTS 标注为"仅在战斗中
  所使用的数据"），用 `action=query&rvsection=3` 批量取。
- **校验基准**：PRTS 的「卫戍协议：盟约/PRTS盟约记录」页镜像了游戏自己的数据（参战干员行 + 自选干员盟约表）。
  上面那条并集规则在该页的自选表上 **28/28 全对**（含双盟约的莫斯提马 = 炎 + 拉特兰），这也是本表的可信度来源。

## 需要留意的判定 (已按用户既定规则取舍)

1. **煌 (`char_017_huang`) 确实是双核心干员**：隐藏势力 `炎;;维多利亚`，游戏行本身也是 `盟约1=炎 盟约2=维多利亚`
   （她的特质会变成烛煌，明确"同时为【炎】【维多利亚】盟约形态"）。数据格式只允许一个值，取**盟约1 = 炎**。
   若日后盟约界面按【维多利亚】处理她，把这一条改成 `victoriaShip` 即可。
2. **9 名卫戍协议专属六星 = null**：`char_608_acpion` 郁金香、`char_609_acguad` Sharp、`char_610_acfend` Mechanist、
   `char_611_acnipe` Stormeye、`char_612_accast` Pith、`char_613_acmedc` Touch、`char_614_acsupo` Raidian、
   `char_615_acspec` Misery、`char_617_sharp2` 领主·Sharp。PRTS 未记录它们的所属势力/隐藏势力 —— 它们在本赛季里是
   **被多个不同盟约的干员共用的"原型"替身**，所以没有单一盟约，只能算协防干员。这是**不确定但无更好答案**的一条。
3. **死芒 (`char_450_necras`)**：阵营是维多利亚（所属势力=维多利亚·塔拉），但游戏固定名册在两个赛季里都把她算作
   **迅捷**（非核心盟约）。此处按用户既定规则（**以阵营为准**）取 `victoriaShip`。
4. **结城理 (`char_4217_makoto`)** 是联动干员：若联动干员一律不应带核心盟约，把这一条改成 `null`（其隐藏势力为拉特兰）。
5. **焰狐龙梓兰 (`char_1048_orchd2`)** 按 `teamId=reserve6` 归为 null；其隐藏势力为哥伦比亚，结论同样是 null。
